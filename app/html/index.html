Como este site chega até você

Cada mudança passa por esta esteira. O único passo humano depois do merge é a aprovação de produção.

  1. 1

    Pull request

    gitleaks, Trivy (imagem e manifestos) e testes das políticas do Kyverno.

  2. 2

    dev

    Merge gera a imagem no GHCR e o Argo CD aplica sozinho.

  3. 3

    Homologação

    Promoção automática. O OWASP ZAP ataca o site e barra regressões.

  4. 4

    Aprovação

    Revisão humana, com o resultado do ZAP em mãos.

  5. 5

    Produção

    PR de promoção mergeado pelo bot. Kyverno valida cada pod.
